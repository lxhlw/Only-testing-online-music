怎么判断？

  1. 提示音能播，但歌曲不能播：重点检查第三方音频格式、直连/代理和地址有效期。
  2. 提示音不能播，networkState=3 或 readyState=0：浏览器没有识别出可播放音频源，优先测试直接打开 MP3。
  3. 提示音不能播，报错误码 3/4：旧 WebView 解码器或系统媒体组件可能不支持该音频。
  4. HTTP 206 正常只能证明分段下载工作，不代表声音一定正常。MP3 失败但 WAV 成功，优先检查 MP3 解码；两者均失败但 Web Audio 成功，优先检查媒体管线；三者均失败需检查系统音量及 WebView 音频输出。
  5. 音频线路报 403/502、超时：先排查网络、证书或 Pages 的媒体服务。
