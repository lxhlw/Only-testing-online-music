# FyMusic — 显式确认的酷狗 → 酷我备用播放（开发分支）

## 本阶段范围

正式 main 不修改、不部署。功能只在 feature/fymusic-playback-verifier 上存在。

在现代 Web 浏览器，用户正在尝试酷狗（KG）曲目且最终无法通过所选音源解析，或其所选固定音质未被 KG 声明支持时，播放器提供 **“查找酷我同曲（手动）”** 入口。这不是自动换源，不会预先搜索或下载酷我资源。

### 用户授权和搜索路径

1. 酷狗曲目尝试失败，或固定音质不受 KG 支持；原歌曲停止，不自动替换。
2. 用户第一次点击“查找酷我同曲（手动）”，才进行一次有 9 秒超时的酷我平台搜索。
3. 最多展示 3 个元数据核对通过的候选版本，清楚标注酷我、歌曲、歌手、时长、专辑，并提示 **元数据一致不等于音频指纹一致**。
4. 用户第二次点击某个候选旁的 **“确认尝试此酷我版本”**，才执行正常的 KW musicUrl 请求并开始播放。
5. 播放成功后，状态显示“已手动确认的酷我备用版本”，且保留实际平台 KW 的曲目来源信息。

### 保守的同曲校验

- KG 原始曲目与 KW 候选必须来自对应的平台；不能以 KG 的歌曲 ID 直接拼出 KW 请求。
- 歌曲标题及歌手经 NFKC、空白/常见标点规范化后严格相等。现场版、翻唱及不同歌手拒绝。
- 两边都必须提供有效时长，误差不可超过 **3 秒**，未知时长直接拒绝。
- 当两边都有专辑信息时，专辑名不一致拒绝。
- 这只是用于 **显示供用户确认的候选过滤**，无法证明两个媒体文件来自相同录音版本；故不允许静默自动播放。
- 用户更换歌曲、切换搜索平台或更换 LX 音源后，旧版搜索回调不得重建候选或启动播放。

### 音质、性能及安全

- 正常 KW 播放沿用当前 LXPlaySettings 和 KW 实际声明的 qualitys；支持固定 FLAC、FLAC 24bit 等高音质选项，不强制 128k。
- 固定音质不受当前 KG 声明支持且用户禁止降级时，不会发出任何猜测的 KG 128k 请求；仍可自行决定是否尝试 KW。
- 仅在用户点击之后才触发跨平台搜索，不增加正常搜索或歌曲播放的网络和主线程负担。搜索超时 9 秒，迟到的回调失效。
- 禁止伪造身份、隐式换歌、在调试日志输出原始歌曲 ID、签名、令牌或媒体 URL。
- 无需适配 Android 4.4。本阶段目标是现代浏览器流畅、清晰、可撤回的用户体验。

### 测试和证据

- scripts/test-fymusic-cross-platform-match.mjs：严格匹配及拒绝不同标题/歌手/时长/专辑。
- scripts/test-fymusic-cross-platform-browser.mjs：受控 KG 解析失败、用户二次点击、实际 KW 播放请求及浏览器解码，含固定 FLAC24bit 质量保留；另覆盖固定格式不受 KG 支持以及过时搜索回调取消。
- GitHub Actions .github/workflows/fymusic-playback-verifier.yml：自动执行单元、现有真实媒体解码及备用流程浏览器测试。
- [第一轮通过的完整浏览器测试 Run 41226233809](https://github.com/lxhlw/Only-testing-online-music/actions/runs/41226233809)：在生成的授权 WAV 校准音频上验证用户确认后流畅播放；这不等同于商业音源的现场可用性。

**尚未完成的外部验证：** 实际野花 Cloudflare 代理对孙燕姿《开始懂了》对应的 KW 录音是否提供稳定可播放媒体链接及正确歌曲内容。必须用真实 Web 解析、媒体解码和可能的音频内容核对，才能宣布该特定歌曲在 FyMusic 中恢复播放。在此之前不得合并到 main 或声称正式站已修复。
